## Reading the scores

- **Strongest:** tokens (71). The colour system is a verified 1:1 copy; the gaps are fonts, shadows and motion.
- **Weakest:** testing (0), documentation (18), coverage and DX (25 each).
- **Largest lever:** Wave 1 of the roadmap. Packaging, provider, typography, tests and Button/Input/Modal parity would move DX, testing, API, a11y and architecture together. Projected after Wave 1: roughly coverage 35, API 70, visual 60, tokens 85, a11y 65, docs 35, testing 45, DX 60, architecture 60 → overall ≈ 55. This is a projection, not a measurement; re-score after the wave lands.
